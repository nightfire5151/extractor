PeopleSoft Autofill — One-Time Setup

Drag this button up into your browser's bookmarks bar. You only do this once.

VDF → PeopleSoft
  1. Drop a VDF above and click Copy all (JSON).
  2. On the Identifying Information tab, click the bookmark once (fills Supplier Name + Short Name).
  3. On the Address tab, create Address ID 1, 2, and 3 with the + button first. Then click the bookmark once — it fills every address record visible on the page.
Fills Supplier Name & Short Name on the Identifying Information tab. On the Address tab it fills every visible address record: Description (1 = LEGAL ADDRESS, 2 = REMITTANCE ADDRESS, 3 = PURCHASE ADDRESS), Address 1, City, State, Postal, and Email ID. Create the three address records yourself first.
